# Система управления заявками УРТК

## Описание проекта

Веб-приложение для управления заявками и задачами в учебном заведении. Система позволяет создавать, отслеживать и управлять заявками от разных аудиторий с различными уровнями приоритета.

## Основные возможности

### 📋 Создание заявок

-   **Название проблемы** - описание технической неисправности или задачи
-   **Привязка к аудитории** - указание конкретного помещения (например, Аудитория №43)
-   **Установка дедлайна** - определение сроков выполнения задачи
-   **Список задач** - возможность добавления нескольких подзадач к заявке (например: "Установка ПО", "Чистка ПК")
-   **Уровни приоритета**:
    -   🟢 Низкий
    -   🟡 Средний
    -   🔴 Высокий

![Создание заявок](/images/TicketPopupCreation.png)

### 👁️ Просмотр заявок

-   Детальная информация о заявке с отображением всех параметров
-   Номер заявки для удобного отслеживания
-   Дата регистрации заявки
-   Информация о заказчике
-   Статус заявки - **"Заявка на рассмотрении у системного администратора"**

![Информация заявки](/images/TicketPopupInformation.png)

### 📊 Управление заявками

**Главная панель** с возможностями:

-   Просмотр списка всех заявок
-   Фильтрация по различным параметрам:
    -   Номер заявки
    -   Название проблемы
    -   Приоритет
    -   Местоположение (аудитория)
    -   Заказчик
    -   Дата создания
    -   Статус выполнения

![Информация о тикетах](/images/TicketsPage.png)

**Статусы заявок**:

-   🟡 На рассмотрении
-   🔵 Выполняется
-   ✅ Выполнена (с возможностью скрытия)

**Режимы отображения**:

-   🔲 Сетка (карточки)
-   ☰ Список (таблица)

![Информация о тикетах](/images/TicketsPage2.png)

### 🎯 Дополнительные функции

-   Переключатель **"Показывать выполненные заявки?"** для фильтрации завершенных задач
-   Кнопка **"Создать заявку"** для быстрого добавления новой заявки
-   Возможность редактирования названия проблемы через иконку карандаша
-   Добавление нескольких задач к одной заявке через кнопку **"Добавить задачу"**

## Технологии

-   **Backend**: FastAPI, Python
-   **Database**: SQLAlchemy
-   **WebSocket**: Для real-time обновлений
-   **Document Generation**: python-docx
-   **Frontend**: React, React Router, SCSS, WebSockets

## Установка

```bash
# Клонирование репозитория
git clone [URL репозитория]

# Установка зависимостей
pip install fastapi uvicorn[standard] websockets python-multipart sqlalchemy alembic python-docx

# Запуск сервера
uvicorn main:app --reload
```

## Использование

1. Создайте заявку через форму "Заявка системному администратору"
2. Укажите название проблемы и выберите аудиторию
3. Добавьте необходимые задачи
4. Установите приоритет и дедлайн
5. Отслеживайте статус заявки в главной панели
